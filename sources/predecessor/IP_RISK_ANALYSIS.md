Compare against event brief inviting a billable startup. These findings do NOT establish that the event lacks a separate license; request signed or written event-specific authorization.

**BAND Privacy (https://www.band.ai/privacy-policy):** cloud and third-party processing conditions apply; the fact that coding agents run locally does not establish that every room message and contextual artifact remains local. The exact fields transmitted in the proposed workflow remain NOT_TESTED.

**Cognee (https://github.com/topoteretes/cognee/blob/main/LICENSE):** Apache-2.0 main LICENSE; commercially permissive subject to notice, attribution/patent and other terms. This license does not confer rights to ingested third-party source datasets, knowledge-graph claims or human subjects data. All graph outputs must bind back to source permissions.

**Flexprice (https://github.com/flexprice/flexprice):** repository declares AGPL-3.0 open core and separately licensed enterprise components. AGPL §13 applies to certain modified versions served to users over a network, and copying/adaptation into a combined proprietary codebase can change obligations; mere separate service/API use must be assessed on actual implementation, not assumed a violation. Commercial service use under AGPL is not categorically forbidden.

**SeedGraph (GitHub connector):** private `biobitworks/seedgraph` root LICENSE blob SHA (Git object, not SHA-256) `8151ec38cffeecc4878d166b06fa32169324f02d` describes AGPL-3.0-or-later community use OR commercial license negotiated with BiobitWorks. It is not evidence that such a separate commercial license has been executed. Exact license version for deployed bytes must be pinned.

**Snyk (https://docs.snyk.io/snyk-data-and-governance/how-snyk-handles-your-data):** per-product access/retention differ; Snyk Code scans repository code and keeps selected result metadata. Do not scan inherited private IP or restricted data without authority.

**AI attribution/inventorship:** The U.S. Copyright Office (2025) states purely AI-generated expression may not qualify for copyright without sufficient human authorship (https://www.copyright.gov/newsnet/2025/1060.html). The USPTO revised November 2025 guidance requires natural-person inventors for AI-assisted patents (https://www.uspto.gov/subscription-center/2025/revised-inventorship-guidance-ai-assisted-inventions). Identify humans contributing to conception and protect invention disclosure timing (https://www.uspto.gov/patents/basics/international-protection/filing-patents-abroad).

## Higher-order linkage analysis — INTAKE_INFERENCE

1. **Dataset -> fragment/feature -> embedding -> Cognee graph -> BAND room -> public demo:** a representation change, de-duplication, embedding or hashing does not establish new transfer or publication rights. A private restricted source may leak through factual nodes, prompt snippets, retrieval results, captions, tokens or video screens. Propagate rights along every derived observation and graph edge.
2. **SeedGraph -> FCO/FCG -> Cognee -> commercial product:** separation of code, graph and service scopes is material to copyleft and ownership. An independent adapter is not automatically under the same license, but concrete copying/derivation/combination must be assessed.
3. **Pre-existing invention -> agent instructions -> BAND feedback -> demo/repo:** protect unpublished know-how and invention disclosures from terms treating certain platform-specific feedback as assigned, and from patent-relevant public disclosure. Do not assume all user content is platform feedback; tag and review the distinction.
4. **Cognee memory -> improve/forget -> derivative vector/caches -> retraction:** deletion or license withdrawal should propagate to graph nodes, embeddings, pointers, cached summaries and downstream claims. This retraction process has not been executed.
5. **Source corpus -> provenance hash -> Merkle/MMR -> IP assertion:** file hashing proves byte identity, not legal authorship, compliance, invention conception, scientific truth or commercial authorization. Graph inclusion establishes lineage only where receipts exist.
6. **Human+AI work -> new code or candidate patent:** record actual individual human creative, inventive and engineering contributions and pre-existing code sources, with explicit contributor agreements when multiple people participate.
